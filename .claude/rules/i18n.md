# i18n (next-intl)

- Locales `fr` (default) + `en`. Every key lives in **both** `fr.json` and `en.json`;
  `src/messages/messages.test.ts` fails on a missing key. `src/global.d.ts` types messages from
  `fr.json`, so French is the reference shape.
- Navigation comes from `@/i18n/navigation` (`Link`, `usePathname`, `useRouter`) —
  `next/link` / `next/navigation` drop the `/fr` | `/en` prefix (the hook refuses them).
  `redirect` / `getPathname` aren't re-exported yet: add them there on first use.
  `notFound` stays on `next/navigation`.
- `src/proxy.ts` is Next 16's `middleware`. It doesn't exist in the static export: the deploy
  branch handles the root locale redirect itself, so don't put logic here that the site needs.
